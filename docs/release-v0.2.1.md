# MindBoard 0.2.1

Two fixes for sticky notes:

- Empty notes now stay on the board when you finish editing, including their chosen color. Escape still cancels a new note.
- Editing uses the full height of tall notes, removing the premature scrollbar caused by the previous editor height limit.

## Download for Windows x64

- **MindBoard_0.2.1_x64-setup.exe**: installer, with Start menu access.
- **MindBoard_0.2.1_windows-x64-portable.zip**: extract and run `MindBoard.exe` without installation.
- **SHA256SUMS.txt**: checksums for both downloads.

Existing `.mindboard` files remain compatible. The app requires Microsoft Edge WebView2; the installer can obtain it when needed. Downloads are not code-signed, so Windows may display its unrecognized-app prompt.

Source code and usage documentation: [A7E7-Studios/mind-board](https://github.com/A7E7-Studios/mind-board).
